# ENET'COM Template Rules

This folder contains the official ENET'COM report template and formatting requirements.

These files are authoritative for formatting, layout, cover page, page style, chapter style, lists, captions, margins, bibliography style, and final LaTeX structure.

## Usage rule

The content of the Itqan report may be compressed, rewritten, and improved, but the final LaTeX output must respect the official ENET'COM template.

## Priority

For formatting decisions, use this order:

1. Official ENET'COM template.
2. Supervisor instructions.
3. Current v0 LaTeX structure.
4. Reference excellent reports.
5. Claude Code suggestions.

## Important

Reference reports are only quality benchmarks.

The official ENET'COM template is the formatting source of truth.
